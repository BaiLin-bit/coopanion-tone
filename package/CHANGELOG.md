# 更新日志

## 0.1.0

首个版本。

- 规则表：34 条正则，覆盖小作文、升华、讨好、翻译腔、AI 惯用词与句式；另加破折号补丁腔、三项等长排比、「比…还…」比较级、夸张评价收尾、单条过长。
- 工具 `deai_check`：把一段话丢进去，返回命中清单与改法；`mode: "rewrite"` 再给一版规则替换后的文本。
- 本地检查服务：默认 `127.0.0.1:18770`，被占自动顺延；起好后把实际地址写进 `tone-service.json`，接入方读它而不是猜端口。接口 `POST /check`、`POST /note`、`GET /health`。
- 面板「腔调记录」：最近 15 条，区分「拦下」与「发出」；内置接入指南、可复制的示例代码与提示词。
- **本扩展不修改任何人的代码**：想拦截某处发言，需由使用者在那个 World 发送前调用检查服务。示意见 `docs/接入指南.md`。
